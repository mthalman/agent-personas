# Agent Personas

Agent personas are specialized behavioral profiles that define how AI assistants should approach different types of tasks and interactions. By adopting specific personas, AI agents can provide more targeted, contextually appropriate responses and assistance tailored to particular domains, roles, or use cases.

This repository provides a collection of sample agent personas that demonstrate different specialized approaches for AI assistants, covering various professional roles and technical domains. The personas are formatted with a header that is compatible with [Claude Code subagents](https://docs.anthropic.com/en/docs/claude-code/sub-agents).

## Why Agent Personas Are Useful

Agent personas enable AI assistants to provide specialized expertise and consistent behavior tailored to specific domains and tasks. By adopting appropriate personas, AI can deliver role-appropriate communication styles, enhanced problem-solving approaches, and improved user experiences through better contextual understanding. This flexibility allows users to select the most suitable "expert" for their current needs, effectively transforming general-purpose AI assistants into specialized consultants with domain-specific knowledge and methodologies.

## Available Personas

- 🔍 [Analyzer](personas/analyzer.md) - Root cause analysis and investigation specialist for debugging, troubleshooting, and systematic problem-solving
- 🏗️ [Architect](personas/architect.md) - Systems architect specialist for long-term thinking, scalability design, and architectural decision-making
- ⚙️ [Backend](personas/backend.md) - Backend specialist for server-side development, API design, database architecture, and infrastructure systems
- 👨‍💻 [Code Reviewer](personas/code-reviewer.md) - Principal engineer-level code reviewer specializing in architectural vision, strategic code quality, and technical leadership
- 🎨 [Frontend](personas/frontend.md) - Frontend specialist for UI/UX development, user-facing applications, and client-side optimization
- 👨‍🏫 [Mentor](personas/mentor.md) - Educational guidance and knowledge transfer specialist for learning, teaching, and skill development
- ⚡ [Performance](personas/performance.md) - Performance optimization specialist for bottleneck elimination, scalability, and system efficiency
- 🤖 [Persona Architect](personas/persona-architect.md) - AI agent persona design specialist for creating, optimizing, and managing AI persona systems
- 🧪 [QA](personas/qa.md) - Quality assurance specialist for testing, quality gates, and defect prevention
- 🔧 [Refactor](personas/refactor.md) - Code quality and technical debt management specialist for refactoring, code cleanup, and maintainability improvement
- 🔒 [Security](personas/security.md) - Security specialist for threat modeling, vulnerability assessment, and secure development practices

Use the [meta-persona](personas/persona-architect.md) to create new personas.
